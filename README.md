#  LearnBridge AI

### Bridging Educational Gaps with Local AI

LearnBridge AI is an AI-powered tutoring assistant built to help WAEC and JAMB students in Nigeria learn more effectively through personalized explanations, guided practice, and interactive quizzes.

Powered by Google's Gemma models running locally with Ollama, LearnBridge AI provides accessible educational support for students in low-resource environments.

---

#  Problem Statement

Millions of students sit for WAEC and JAMB examinations yearly, yet a large percentage struggle to achieve competitive scores.

Many students lack:
- Access to quality tutoring
- Personalized learning support
- Consistent practice materials
- Affordable educational resources

LearnBridge AI was built to bridge this gap using local AI.

---

#  Solution

LearnBridge AI provides:

✅ Simple step-by-step explanations  
✅ WAEC & JAMB-focused tutoring  
✅ AI-generated practice quizzes  
✅ Personalized learning support  
✅ Local AI inference using Gemma  
✅ Low-resource friendly architecture  

---

#  Technologies Used

- Python
- Streamlit
- Ollama
- Gemma 4
- Gemma 3
- Local LLM Inference

---

#  AI Models

This project supports:

- `gemma4:e2b`
- `gemma3:1b`

Gemma 4 is used as the primary reasoning model, while Gemma 3 serves as a lightweight fallback option for lower-resource devices.
